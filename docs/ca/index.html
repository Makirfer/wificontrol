Horaris automàtics

Avisos de connexió

T'avisa quan es connecta un aparell concret o un de nou que no coneixes.

Parla directament amb el router. Si el teu no hi és, li pots ensenyar i compartir-lo.

🔒

Privada

Les contrasenyes es desen xifrades al teu mòbil. Sense comptes, sense publicitat, sense servidors.

🎬

Mode demostració

Prova-la sense tocar el teu router, amb aparells d'exemple.

Com funciona

  1. Instal·la l'app i tria el model del teu router (o llegeix-lo de l'adhesiu amb una foto).
  2. Escriu la contrasenya d'accés al router. Es desa xifrada només al teu mòbil.
  3. Posa nom als aparells, marca'ls per a la pausa i crea els horaris que vulguis.

Routers

L'app inclou un catàleg obert de routers de les companyies espanyoles, que completen els mateixos usuaris.
